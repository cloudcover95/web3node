# web3node

**Sovereign Web3 Tensor Engine**

web3node provides decentralized transaction signals and on-chain data ingestion for the JuniorCloud LLC sovereign quant stack.

It serves as the Web3 signal layer that feeds into JuniorStock and higher-level reasoning systems.

## Integration

- Supplies on-chain events and transaction data to **JuniorStock**
- Can be consumed by **BitNet-mlx** reasoning pipelines
- Part of the broader edge-native, air-gapped architecture

JuniorCloud LLC is building a complete sovereign stack where web3node handles the decentralized data ingestion layer.
